# Blazwitcher 拼音搜索

在 Raycast 窗口内搜索 Chrome 标签页、书签和历史记录。保留 A 方案的单栏结构：搜索框、来源筛选、结果数量、网站图标、标题、灰色网址、来源标签和底部操作栏，不显示右侧详情。

**当前限制：行内彩色命中高亮尚未实现。** Clipboard History 使用 Raycast 内部 `HighlightRoot`，第三方 `List.Item` 没有相同接口。搜索仍由 `text-search-engine@1.5.3` 完成，并保留原文命中区间；`zhoubao` 能找到“周报”，但目前列表不会为这两个字着色。不添加「」等标记，也不使用独立浮窗或详情栏替代。

## 安装到 Raycast

Blazwitcher Raycast 目前通过源码安装。需要 macOS、Google Chrome、Raycast，以及 Node.js 22.22.2 或更新版本；不需要全局安装 Raycast CLI。

```bash
git clone https://github.com/cjinhuo/blazwitcher-raycast.git
cd blazwitcher-raycast
npm ci
npm run dev
```

终端出现 `ready - built extension successfully` 后，打开 Raycast，搜索并运行“搜索浏览器”。首次切换标签页时，macOS 可能询问是否允许 Raycast 控制 Google Chrome，请按提示授权。

`npm run dev` 会把扩展导入 Raycast 并监听源码修改。导入完成后可按 `Ctrl+C` 停止监听；需要升级时，在仓库中执行 `git pull`、`npm ci`，再运行一次 `npm run dev`。详细的调试、权限排查与卸载步骤见 [贡献指南](CONTRIBUTING.md)。

## 使用

统一入口首次打开时会先展示 Chrome 标签页，再渐进加入历史和书签，与 Chrome 扩展的首屏顺序保持一致。

| 命令         | 范围                       |
| ------------ | -------------------------- |
| 搜索浏览器   | 标签页、书签、历史统一搜索 |
| 搜索标签页   | Chrome 所有可读窗口的标签  |
| 搜索书签     | 所选 Chrome 配置的书签     |
| 搜索历史记录 | 所选 Chrome 配置的最近历史 |

统一入口支持来源下拉框和 `/t`、`/b`、`/h` 前缀，其他入口固定来源。

“全部来源”会在匹配后按相同的非空标题或完整 URL 去重，与 Chrome 扩展一致：优先保留已打开标签页，其次书签、历史；多个真实标签页仍全部保留。即使版本参数或登录跳转地址不同，相同标题也会合并。结果数与分页以去重后为准，复制和跳转仍使用保留记录的原始 URL。需要查看各个版本或记录时，可切换单一来源；指定 URL 片段搜索也不会被未命中的标签遮住。

搜索优先采用标题中的完整命中（包括中文拼音和首字母），再匹配网址或标题与网址的组合，避免网址中的同名片段降低标题相关度。多个词用空格分开；针对短词占用长词位置造成的漏结果增加重试，例如 `git github` 可以找到 `GitHub / git guide`。

统一入口按 `⌘⇧0/1/2/3` 可分别切换全部、标签页、书签、历史记录，也可在 `⌘K` 动作菜单选择来源。切换保留关键词并移除旧来源前缀，例如 `/h zhoubao` 切换到标签页后变为 `zhoubao`。下拉框始终显示当前有效来源，空结果时也能切换。在扩展设置的“来源切换快捷键”中可改用 `⌃⇧0/1/2/3` 或关闭快捷键，更改后重新打开命令。

- 上下键选择，Enter 切换标签或打开地址；失败时保留结果。
- `⌘C` 复制原始完整 URL，`⌘R` 刷新，`⌘K` 打开原生操作菜单。
- 操作菜单可切换 Chrome 配置及打开扩展设置。
- 历史默认读取 20,000 条，上限 100,000 条；全部配置合并后仍受总上限约束。
- 历史结果右侧显示最近访问的相对时间，悬停查看本机时区的完整日期和时间；统一入口与历史入口均支持。
- 无痕标签默认排除，设置位于 Raycast 扩展偏好。
- 普通标签页可通过官方 Raycast Browser Extension 显示网站图标。它是可选增强：未安装时不弹安装提示；调用失败、超过 1.5 秒、图标缺失或图片加载失败时保留来源图标。书签、历史和无痕标签保持原有来源图标。按 `⌘R` 刷新或重新打开命令时重新获取图标，未订阅实时图标变化。
- 默认启用启动预览缓存：先展示上次的部分书签、历史，再用实时完整结果替换；预览阶段显示“已加载结果”和缓存提示。可在扩展设置关闭，或在动作菜单选择“清除启动缓存”。标签页始终实时读取。

当前原生列表的标题、网址在同一行展示，行高、灰色选中背景、截断和明暗主题由 Raycast 管理；SDK 没有自定义双行 DOM 布局接口。

## 数据与隐私

搜索与索引在本机处理，不上传到搜索或图标聚合服务，不持久化完整浏览索引。启用官方浏览器扩展时，Raycast 按 API 返回的 favicon 地址加载图片；本扩展不读取或转发 Chrome Cookie。权限提示归属 **Raycast**。

图标通过 `BrowserIconAdapter` 独立异步加载，不参与搜索索引、排序或跳转。当前实现是 `RaycastBrowserIconAdapter`，只对 ID 与 URL 同时匹配的普通标签补图标；未匹配时沿用来源图标。搜索和分页共享同一数据版本的请求，刷新后重新读取；列表不依赖具体图标提供方。JXA 仍负责读取标签和跳转。

启动预览由 Raycast Cache 存在本机：每个配置最多 100 条书签、100 条历史，有效期 5 分钟，总容量 512 KB，单来源序列化大小不超过 128 KB。仅保存标题、网址及必要的记录字段，不保存配置路径、标签页或无痕记录。过期预览不再使用；关闭该功能后不再读取或写入预览缓存。

SQLite 使用只读查询，锁冲突时读取稳定临时快照，不改写 Chrome 源数据库。标签按真实 ID 重新定位，避免关闭或跨窗口移动后误切标签。单来源读取失败保留其他来源。查询序号和数据版本阻止过期结果被复制或打开。
